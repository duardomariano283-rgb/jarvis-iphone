# JARVIS para iPhone — versão com ajustes de voz

## O que mudou
- Seleção da voz em português disponível no iPhone/Safari.
- Ajustes de tom e velocidade para uma fala mais grave, calma e elegante.
- Botão para testar a voz e salvar preferências.
- Reconhecimento de voz em português brasileiro e envio por texto.

## Instalar/atualizar no GitHub Pages
1. Abra o repositório `jarvis-iphone` no GitHub.
2. Substitua os arquivos `index.html`, `manifest.webmanifest` e `sw.js` pelos desta versão.
3. Aguarde o GitHub Pages publicar a atualização.
4. Abra o site do JARVIS no Safari e recarregue a página.
5. Em Configuração de Voz, escolha uma voz `pt-BR`, teste e salve.

## Importante
Esta versão ainda usa as vozes sintéticas oferecidas pelo iOS/Safari. Não reproduz nem clona a voz exata do dublador.
O protótipo ainda não está conectado a uma IA generativa; os comandos respondidos são básicos.
O reconhecimento de voz do Safari pode variar conforme a versão do iOS e a permissão do microfone.
